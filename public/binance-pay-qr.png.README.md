# QR Code Binance Pay

Déposez ici votre QR Code Binance Pay au format PNG (ou JPG / WEBP) sous le nom
exact :

    public/binance-pay-qr.png

Il sera automatiquement servi par le checkout à `/binance-pay-qr.png` et affiché
à côté du bloc « Destinataire : Nexora Smart Services ».

Recommandations :
- Format PNG carré, min. 512×512, fond blanc, marges ≥ 20 px.
- Le QR doit correspondre au compte **Nexora Smart Services** (celui qui apparaît
  aux clients).
- Si vous changez le QR, remplacez simplement ce fichier — aucun redéploiement
  de code n'est nécessaire côté logique de paiement.
