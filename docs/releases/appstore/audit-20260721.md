## Détail par catégorie

### 1 · HTML SSR initial (fuite critique)

`src/routes/__root.tsx` définit un `head()` statique qui ne connaît pas l'hôte de la requête. Contenus émis dans le HTML servi sous `app.nexora-iptv.com` :

- `<title>Nexora IPTV</title>` (ligne 83)
- `<meta name="description" content="Premium IPTV service with thousands of live channels…" />` (ligne 84)
- `<meta name="author" content="Nexora IPTV" />` (ligne 85)
- `<meta property="og:site_name" content="Nexora IPTV" />` (ligne 91)
- `<meta name="twitter:title" content="Nexora IPTV — Unlimited Entertainment…" />` (ligne 94)
- `<meta name="twitter:description" content="Premium IPTV service. Access thousands of channels…" />` (ligne 95)
- `<link rel="manifest" href="/manifest.webmanifest" />` (ligne 103, manifest non neutre)
- `<link rel="alternate" type="application/rss+xml" title="Blog Nexora IPTV — RSS" ... />` (ligne 114)
- JSON-LD `@graph` → `Service` avec `serviceType: "IPTV streaming subscription"` (lignes 134-141)

`AppStoreGate` est un composant React à effet différé — il ne s'exécute pas côté serveur, donc le HTML transmis au navigateur (et à tout scanner Apple, curl, wget, crawler) reste truffé de termes IPTV.

## Remédiation obligatoire (avant Xcode)

Ordre recommandé, du plus impactant au plus mineur :

1. **Rendre le Gate serveur-conscient.** Détecter `Host: app.nexora-iptv.com` dans le `head()` de `__root.tsx` (ou dans un middleware TanStack Start) et retourner un jeu de balises neutres (titre « Nexora », description « Your premium personal hub… », `og:site_name`, `twitter:*`, JSON-LD réduit à `WebSite`, `manifest → manifest.appstore.webmanifest`, hreflang supprimés, RSS supprimé).
2. **Bloquer les chunks sensibles au niveau du build.** Ajouter dans `vite.config.ts`, sous `VITE_APP_STORE_MODE`, un plugin qui exclut les routes suivantes du `routeTree.gen.ts` (ou les remplace par des stubs vides) : `catalog`, `reseller`, `legal-guide`, `fr.guide-iptv`, `en.guide-iptv`, `blog.best-iptv-2026`, `espace-client.downloads`, `iptv-delivery*`, `iptv-import.*`, `DeliveryPreview`, `admin.*`, `ncc.*` (le NCC ne doit pas être bundlé pour ce build).
3. **Neutraliser `SANITIZE_DICT` dans le bundle**. Deux options : soit transformer les regex en littéraux encodés à la construction (ex. base64 → décodage runtime), soit — plus propre — supprimer `AppStoreGate` du build quand le mode App Store est actif (les fuites qu'il corrigeait n'existent plus après correctif 1+2).
4. **Servir `manifest.webmanifest` et `llms.txt` dynamiquement.** Convertir en routes serveur (`src/routes/manifest[.]webmanifest.ts`, `src/routes/llms[.]txt.ts`) qui branchent sur l'hôte, exactement comme `sitemap.xml`/`rss.xml`/`robots.txt`.
5. **Purger le `precacheAndRoute` Workbox.** Dans `vite.config.ts`, ajouter `workbox.globIgnores: ['**/iptv-*.js', '**/*.iptv.*.js', '**/*guide-iptv*.js', '**/reseller-*.js', '**/catalog-*.js', '**/blog.best-iptv-*.js', '**/DeliveryPreview-*.js']` **et** filtrer `manifestTransforms` pour retirer les URLs sensibles.

Après application, relancer :

```bash
VITE_APP_STORE_MODE=1 bun run build
bash scripts/check-appstore-build.sh dist/client
node scripts/audit-appstore.mjs dist/client
```

Le rapport JSON `docs/releases/appstore/audit-<date>.json` doit sortir avec `"pass": true` et `"findings": []` **avant** `bunx cap sync ios`.
